# 05 故障排查、速查与实验记录

| 现象 | 优先检查 | 处理方向 |
|---|---|---|
| 空载0.00 A | 没有负载，电流很小 | 不把实际电流当限流设定 |
| 设5 V却很低，CC亮 | 限流过低、负载过重、短路 | 先移除负载排错，不立即开到5 A |
| 无负载电压也不正常 | 模式、旋钮、显示、万用表 | 独立低压复核，异常停机 |
| 转CURRENT电压没变 | CV且负载没达到限制 | 用计算过的电阻验证 |
| 转VOLTAGE电压不变 | CC、跟踪从路、范围问题 | 查工作模式和负载 |
| 从路不跟踪 | 限流、按钮状态、外部接线 | 移除负载后按对应图核对 |
| 并联电流不均 | 外部连线/接触、模式 | 停供后检查，不加大电流试错 |
| 串联一接SDS异常 | 地夹/输出地片造成旁路短路 | 断开负载，重画地路径 |
| 固定5 V不随旋钮变 | 使用固定路 | 正常，不靠可调路按钮控制 |
| 板端电压低于电源 | 线阻、接触、CC | 直接测板端，核查电流 |
| 电阻发热 | 功耗、额定、散热 | 停供后核算P和余量 |
| 小电流面板显示0 | 显示分辨率不足 | DM40A压降法/正确串联法 |
| 示波器纹波比规格大 | Vpp/RMS、带宽、探头地线 | 条件对齐后再判断 |
| 气味/烟/异常发热 | 设备/接线故障 | 停机，由合格维修人员处理 |

## 日常速查

开机：不接负载 → 独立模式 → 电压从低起 → 限流验证 → DM40A核对 → 接负载。
关机：先断开负载 → 关电源 → 确认残余电压 → 收线。
改模式：移除负载、关机 → 按原厂图接桥接线 → 核对地关系 → 空载低压验证 → 再接负载。
