# 01 面板、旋钮、端子与安全

## 1. 根据功能识别面板

本机实物面板尚未见到，以下以官网系列手册图2为参考。手册PDF第7页有编号图，实际丝印优先，不把图号当本机通道名称。

| 标识/部件 | 含义 | 怎么理解 |
|---|---|---|
| VOLT / V显示 | 实际输出电压 | 不一定等于旋钮希望的值 |
| AMP / A显示 | 实际输出电流 | 空载通常很小，不能据此读出限流设定 |
| VOLTAGE旋钮 | 电压设定 | 先调小，再逐渐增加并核对 |
| CURRENT旋钮 | 电流上限/恒流设定 | 不直接决定CV状态的实际电流 |
| CV指示 | 恒压工作 | 当前负载需求未超过电流约束 |
| CC指示 | 恒流工作 | 实际电流被限制，输出电压调整 |
| INDEP/SER/PAR或TRACKING | 两路模式控制 | 第一课保持独立 |
| 红色+输出端 | 该路正输出 | 接负载正端 |
| 黑色−输出端 | 该路负输出 | 接负载回路参考 |
| 接地符号端子 | 机壳/保护地端 | 不默认等于该路负端 |
| 固定5V端子 | 独立固定输出 | 不受可调路电压旋钮控制 |
| POWER | 主电源 | 不能默认另有输出关闭功能 |

有些版本有粗调/细调；只有本机确实标注时才按对应旋钮使用。不要把另一台现代电源的数字菜单、预设或OCP按钮套到本机。

## 2. CV与CC的实际含义

例：电压设5 V、限流设0.10 A，负载为100 Ω。
理想需求I=5/100=0.05 A，未到上限，所以约5 V/50 mA，CV。

把负载变成10 Ω，5 V时需求0.5 A，超过0.1 A限制。电源进入CC，理论电压约I×R=1 V，电流约0.1 A。这不是电源自动坏了，而是限制在发挥作用。

限流不会保证精密芯片绝不损坏：瞬态、输出电容能量、过压、极性错误仍可能造成损伤。限流也不等于过流立即断电。

## 3. 负端、实验GND与保护地

−是该输出相对于+的回路端；GND在电路里是选定的参考节点；保护地是安全接地系统。三者不能只凭黑色/绿色相同就混为一谈。

不能移除电源或SDS的三芯电源保护地。若存在输出负端到机壳地的外部连接片，改变双路模式前必须按原厂连接图检查；“移除输出连接片”与“拔保护地”是完全不同的事。

SDS普通探头地夹连接到仪器保护地，两个通道地夹共地。它一接入就可能把所夹实验节点固定到地，重新检查所有输出/USB/负载的地路径。

## 4. 初学操作边界

- 使用合规保护接地插座，放稳、通风，不挡风口。
- 输入电压选择必须与当地市电和铭牌一致；若有110/220切换，断电拔插头后按标识处理，不带电切换，也不凭地区推测当前档位。
- 第一次保持两路独立，未使用输出不接负载。
- 用绝缘良好且额定合适的线；先检查极性和夹具。
- 不带负载切换独立/串联/并联，不把外部电源或电池反接到输出端。
- 电机、继电器线圈等感性负载需要专门的反向能量/续流保护，不作为第一课。
- 出现异常热、气味、烟或控制失效，移除负载并停机。

固定5 V输出也不是“永远安全”：接到3.3 V芯片、反接或电路异常仍可损坏负载。先用DM40A量实测电压再用。

## 5. 面板读数精度

官网给出电压显示±1%+2字、电流±2%+2字。它们不是DM40A的精度，也不能因为电源显示5.00就认为实际误差为零。

以万用表核对负载端电压，避免线阻导致“电源端正常、板端偏低”。很小电流受面板分辨率影响，0.00 A不代表绝对无电流。
