## 型号基本能力

依据[官网](https://longweielec.com/product/tpr-3005-2d)：
两路可调直流输出，各0～30 V、最大5 A；另有固定5 V/3 A；支持独立、串联、并联；有恒压/恒流自动转换。

5 A是能力上限，不是电源会强行向所有负载灌5 A。实际电流由负载和电压决定，达到所设上限时进入恒流，电压可能下降。

第一课只使用独立模式、单路5 V和电阻负载。串联最高电压能力与并联大电流能力不作为初学实验目标。

## 重要操作顺序

厂家要求先开电源再接负载，关电源前先断开负载。为避免空载开关瞬态加到电子板，按此顺序：
电源不接负载开机 → 设电压和限流 → 万用表核对 → 接负载 → 测量 → 先断开负载 → 关电源。

断开负载指输出侧安全连接，不是拔电源保护地。没有独立输出开关的版本，不能把主电源开关当作带负载的输出启停键。
