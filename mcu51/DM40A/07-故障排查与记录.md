# 07 排错、速查和实验记录

## 故障表

| 现象 | 先检查 | 不要直接下的结论 |
|---|---|---|
| 数字始终不变 | HOLD、当前模式、接触 | 电路一定没有变化 |
| 电压负号 | 两笔极性与参考点 | 表坏了 |
| 电压接近零 | REL、插孔、测点、供电 | 自动判短路 |
| 5 V PWM 读约 2.5 V | 用 SDS 查高低平台与占空比 | GPIO只能输出2.5 V |
| OL | 量程、开路、模式、接触 | 元件一定损坏 |
| 小阻值不为零 | 表笔与接触电阻 | 短路线有真实大电阻 |
| 在板电阻偏小 | 并联支路、残余电压 | 电阻阻值变小 |
| 通断一开始响后不响 | 电容充电及阻值变化 | 只凭第一声判短路 |
| LED 不亮/OL | 极性、压降、测试能力 | LED一定坏 |
| 电容量慢/漂 | 放电、接触、本底、离板 | 立即更换元件 |
| 电流为零 | 串联路径、模式、保险、供电 | 自动增加电压 |
| 串表后板子复位 | 负担电压、接触、供电路径 | 板子必然有故障 |
| 电流远超预期 | 立即断电查旁路短路 | 等自动保护解决 |
| AC读数与SDS不同 | RMS/Vpp、耦合、偏置、频带 | 谁最后一位不同谁不准 |
| Hz不稳定 | 幅值、波形、频率触发与噪声 | 晶振一定异常 |
| 信号源无输出 | 端口、输出开关、线、设置 | 将线强插其他端口 |

## 测量速查

| 目标 | 插孔 | 功能 | 接法 |
|---|---|---|---|
| 电池/板供电 | COM+电压孔 | DC V | 并联两节点 |
| 隔离低压交流 | COM+电压孔 | AC V | 并联，核对频带 |
| 几mA电阻负载 | COM+电流孔 | DC 电流 | 断电开路后串联 |
| 电阻/通断/二极管/电容 | COM+元件孔 | 对应功能 | 断电、放电后跨元件 |
| 方波频率 | COM+V/Hz孔 | Hz | 低压信号与参考地 |
| 发生器 | 专用OUT及指定线 | 发生器 | 先关闭再接线，接收端验证 |

## 建议的首轮六次练习

1. 1.5 V 电池电压与反接符号。
2. 独立 1 kΩ/10 kΩ 与表笔本底。
3. 导线通断与普通二极管。
4. 隔离5 V+1 kΩ，压降法/串联法测电流。
5. 分压与 PWM/RC。
6. DM40A 发生器送 SDS，量频率/幅度，做 RC 输入输出比较。
