## 与已有示波器教程配合

[你的 SDS1202X-E 项目](../SDS1202X-E/README.md) 负责观察电压随时间的变化；DM40A 万用表负责直流电平、阻值、通断和电流等基础检查。DM40A 也集成示波器/发生器，但万用表的趋势图不等于高速波形。

推荐每个实验：先画接线并预测 → 用 DM40A 检查静态值 → 用 SDS 看动态波形 → 比较与记录。不要将两台仪器读出的不同物理量硬判定为谁更准。
