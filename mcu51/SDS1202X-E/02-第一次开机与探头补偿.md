# 02 第一次开机：只测机器自己的校准方波

目标：不接开发板也能显示稳定方波，弄清倍率、时间档和电压档。准备示波器、一根探头、非金属补偿调节工具。

## 1. 开机前

检查电源线、探头绝缘和插头完好；放在通风稳定的桌面，接有正常保护地的插座。不要挡风口。开机后出现自检和继电器动作声音通常属于启动过程。

若要将菜单改成中文，从 Utility（系统）中的 Language（语言）寻找简体中文，可能需翻页。面板印字仍可能是英文，本项目同时提供英文名和中文含义。

## 2. 得到第一条波形

1. 保持未接任何外部电路。
2. 恢复默认设置。双通道面板有些功能是共用按键：寻找标有 Default 的按键/辅助功能，若面板与教程不同，以本机说明书和实际菜单为准，不套用四通道按钮位置。
3. 探头开关调 10X，BNC 插入 CH1 并锁紧。
4. 打开 CH1 通道菜单，把 Probe（探头倍率）设 10X。
5. 地夹接前面板校准输出旁标有接地符号的端子，尖端接补偿信号输出端。
6. 按 Auto Setup（自动设置），先找到方波。
7. 观察是否出现重复的高低平台。先以约 1 kHz、周期约 1 ms 为观察参考；具体幅值与频率以本机标识、手册和测量为准，不预设成固定 5 V。

如果无波形：确认接的是补偿输出而不是地端、CH1 已开启、采集处于 Run、耦合是 DC，倍率匹配。

## 3. 手动重现，才算真正开始使用

找到波形后改成以下起点，若显示幅值不合适再调：

| 项目 | 起点 | 调整理由 |
|---|---|---|
| 探头/通道倍率 | 都为 10X | 保证显示电压正确 |
| 耦合 | DC | 保留高低电平的实际位置 |
| 电压档 | 1 V/div | 让波形占大约 3～6 个竖格 |
| 时间档 | 200 μs/div | 约 1 kHz 时能看数个周期 |
| 触发类型 | Edge，边沿 | 从某个电压穿越点开始 |
| 触发源 | CH1 | 触发来自接探头的通道 |
| 方向 | Rising，上升沿 | 以从低到高为起点 |
| 触发电平 | 高低平台中间 | 能被每周期穿越 |
| 触发模式 | Auto，自动 | 先方便看到信号 |

不要把垂直位置旋钮当电压档，不要把水平位置旋钮当时间档。电压档改变高低平台距离，垂直位置只移动波形；时间档改变屏幕显示多少周期，水平位置改变观察的时间位置。

## 4. 调探头补偿

将方波平台和边沿放大到容易观察，不要只看一个毛刺。找到探头厂家注明的低频补偿调节孔，使用非金属工具小幅调整。

| 外形 | 可能解释 | 做法 |
|---|---|---|
| 边沿后逐渐爬升、平台圆弧 | 补偿不足 | 小幅调整，直到平台接近平直 |
| 边沿后有明显过冲、随后回落 | 补偿过度或接线寄生 | 先优化接地，再小幅调整 |
| 平台平直、边沿自然 | 补偿基本合适 | 停止调节并记录 |

不要把所有尖峰都归结为补偿；长地线、探头带宽和输出端特性也可能影响边沿。调节目标不是让有限带宽设备显示数学上绝对垂直的边沿。

每根探头分别检查；更换通道或探头后再核对匹配。第二根探头接 CH2 重复上述过程，两个地夹都接补偿地端。

## 5. 练习题

1. 时间档从 200 μs/div 改到 500 μs/div：同一屏会显示更多还是更少周期？
2. 电压档从 1 V/div 改到 2 V/div：波形变高还是变矮？
3. 探头是 10X、菜单是 1X，读数会如何改变？
4. 触发电平高于最高平台，会不会有真正的边沿触发？
5. 按 Run/Stop 冻结波形后，新输入还会实时更新吗？

答案：更多；变矮；约为真实电压的十分之一；不会（自动模式仍可能刷新）；不会。

## 6. 保存本次证据

记录两根探头型号、补偿状态、CH1/CH2 倍率、测得 Vpp 和周期，保存屏幕截图。成功标准：不用 Auto Setup，也能手动调出稳定方波，并解释每个设置。
