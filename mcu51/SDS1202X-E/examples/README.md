## 使用前提

- 使用支持经典寄存器定义的 Keil C51 环境，reg51.h 是否适用于芯片需核对。
- P1.0 确认是可用 GPIO，未被板载外设或复用功能冲突占用。
- 确认供电、电平、输出结构、晶振和下载方式。
- 每个文件单独建立工程，二者都有 main，不能同时加入同一个目标。
- 探头地夹接板 GND，尖端接实际引出的 P1.0；不要根据 DIP 脚号猜不同封装位置。
- GPIO 不直接带电机、继电器、喇叭或大电容；RC 实验必须经串联电阻。
- delay_units 是忙等待，真实时间受时钟、机器周期和优化影响；不是毫秒函数，不能用循环次数作为精确频率证明。

## 在 Keil 中准备工程的通用过程

1. 根据完整 MCU 型号新建独立项目，选正确芯片；若列表无型号，先按厂家工具文档处理，不随便替代。
2. 根据工具链要求决定是否加入启动文件。
3. 加入其中一个 .c 文件，设置正确晶振和与芯片匹配的选项。
4. 编译并检查全部错误和警告，记录编译器版本及优化。
5. 按该板厂商说明生成下载格式、选择下载软件和接口。
6. 下载完成后再观察波形，用实测频率调整延时；不能把“编译成功”写为“实机成功”。
