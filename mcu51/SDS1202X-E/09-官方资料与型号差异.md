## 双通道与四通道不能混用教程

| 内容 | 本项目处理方式 |
|---|---|
| 两个模拟输入 | 用 CH1/CH2 同时比较输入输出 |
| EXT 输入 | 仅作为外部触发，不算第三个显示通道 |
| 专用 Decode / History 等键 | 不假设与四通道位置相同；双通道可能经复用键/菜单进入 |
| 16 路数字逻辑附件 | 不把四通道型号的 MSO 能力套到 SDS1202X-E |
| 可选信号发生器附件、Bode/Web 等功能 | 不默认用户双通道机具备；需要逐项确认兼容性 |
| 固件 | 只选厂家明确兼容双通道设备的包 |
| 最大采样率和深度 | 以实际通道组合/采集菜单为准，最高值不等于当前值 |

## 资料与实测的证据分层

- 型号规格、面板和基础操作：厂家资料。
- 起始量程、实验步骤、RC/PWM/增益算例：本项目原创教学设计。
- 51 GPIO 特性和定时器配置：必须按用户实际芯片原厂资料确认；本项目暂以有条件假设说明。
- 用户设备实测、程序运行结果：目前没有，不能填成通过。
