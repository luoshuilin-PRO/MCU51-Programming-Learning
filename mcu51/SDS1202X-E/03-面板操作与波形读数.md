# 03 面板操作与波形读数

## 1. 面板英文速查

双通道 SDS1202X-E 存在复用按键，不按四通道机型的位置找键。英文/中文菜单和固件可能不同，先辨识功能名称，再看当前屏幕软键提示。

| 名称 | 含义 | 什么时候用 |
|---|---|---|
| CH1 / CH2 | 通道设置/选择 | 切换当前通道、调整耦合和倍率 |
| Vertical Scale，V/div | 每个竖格多少伏 | 改波形高度 |
| Vertical Position | 竖直位置 | 把波形移开，避免重叠 |
| Horizontal Scale，s/div | 每个横格多少秒 | 改观察的时间范围 |
| Horizontal Position | 水平位置/延迟 | 查看触发前后 |
| Trigger Setup | 触发设置 | 选择源、边沿、模式 |
| Level | 触发电平 | 决定哪个电压交点触发 |
| Auto Setup | 自动设置 | 首次找周期性信号 |
| Run/Stop | 连续运行/停止 | 冻结当前数据 |
| Single | 单次捕获 | 等待并捕获一次事件 |
| Measure | 自动测量 | 显示 Vpp、频率等 |
| Cursors | 游标 | 自己选两个时间或电压点 |
| Acquire | 采集 | 普通、平均等采集设置 |
| Math | 数学运算 | 比较、相减或 FFT |
| Display/Persist | 显示/余辉 | 看抖动、偶发形状 |
| Save/Recall | 保存/调用 | 保存图、数据、设置 |
| Utility | 系统 | 语言、系统状态、自校准 |
| 通用旋钮 | 菜单选择/数值调整 | 先按对应软键再旋转 |
| 屏幕下软键 | 当前菜单项目 | 功能随菜单变化 |

先选对 CH1/CH2 再动垂直控制，观察屏幕哪条通道标签变化，不靠猜测。

## 2. 竖格代表电压

V/div 是“每格电压”，不是整屏电压。例：1 V/div，两个平台相差 4.8 格，Vpp 约 4.8 V。读某一点的绝对电压要从该通道零电平标记起数格，不能从屏幕中心直接数。

- Vmax：记录中的最大电压。
- Vmin：最小电压。
- Vpp = Vmax − Vmin：峰峰值。
- Vmean：选定测量窗口的平均电压。
- Vrms：有效值，含不含直流分量要看所选项目定义。
- 幅度 Amplitude：可能按统计高低平台计算，与含尖峰的 Vpp 并不相同。

对于 0～5 V、50% 占空比的理想方波：Vpp = 5 V，平均值 = 2.5 V，包含直流的 RMS ≈ 3.54 V。三个值不同，各有含义。数字是理论例子。

波形上下超出屏幕意味着输入可能在当前量程内被截断；此时测量结果不可直接信任。先加大 V/div，使整个波形进入有效显示范围。

## 3. 横格代表时间

T = 周期所占格数 × 时间档，f = 1/T。

例：200 μs/div，一个完整周期占 5 格：
T = 1000 μs = 1 ms；f = 1000 Hz = 1 kHz。

常用换算：1 s = 1000 ms；1 ms = 1000 μs；1 μs = 1000 ns。先写单位再代入，避免把 1 ms 误成 1 μs。

占空比 D = 高电平持续时间 / 周期 × 100%。若 T = 1 ms、高电平 250 μs，则 D = 25%。只看波形高低平台不等于知道占空比。

## 4. 时间档怎么选

为了看规律，先显示 2～5 个周期；为了看边沿，再放大到一次转换附近。不是一开始把时间档调到最小。

| 信号例子 | 时间档起点 | 目的 |
|---|---|---|
| 1 Hz 灯闪烁/GPIO | 200 ms/div | 看开关节奏 |
| 100 Hz 方波 | 2 ms/div | 看数个周期 |
| 1 kHz 方波 | 200 μs/div | 读周期和占空比 |
| 9600 bit/s 串口 | 100～200 μs/div | 看约一个字符；单个位再放大 |
| 机械按键抖动 | 1～5 ms/div | 看抖动簇 |
| 供电启动 | 10～100 ms/div | 看上电过程，按实际快慢调整 |

这些是建议起点，屏幕宽度和事件长度也影响设置。串口不连续时自动频率读数可能没有学习意义。

## 5. DC / AC / GND 耦合

- DC：既看直流电平又看变化，测 GPIO、PWM、供电首先选它。
- AC：阻断直流分量，用于放大观察小纹波；并不消除危险电压。低频信号可能因此衰减和畸变，慢方波会出现下垂。
- GND：通道内部用来显示零参考，并非将探头尖端安全接地，也不替代正确接线。

同一个 0～5 V 的方波，用 AC 耦合后可能围绕零轴上下分布。电路没有凭空产生负电源，是测量通道去掉了直流分量。判断电平是否有效时回到 DC。

## 6. 双通道怎么看输入输出

断电接线：两根地夹接同一个 GND；CH1 尖端接输入、CH2 尖端接输出。上电后打开两通道，把它们移到不重叠的位置，记录各自 V/div 和倍率。

两条曲线共用时间轴；可以比较延迟，但若电压档不同，不能根据屏幕高度直接判定增益。增益要用还原后的电压值相除。

例如输入 Vpp = 0.2 V、输出 Vpp = 1 V，幅度增益约 5。输入 1 格、输出 1 格不代表增益 1，要看各通道 V/div。

## 7. 触发不是“给电路发送信号”

示波器触发是为自身采集确定参考时刻，通常不改变电路。稳定显示是反复对齐同类事件。屏幕上的触发位置表示 t = 0；其左侧数据为触发前，右侧为触发后。

每次看波形，至少读：通道、倍率、耦合、V/div、s/div、零点、触发源/电平、Run/Stop 状态、实际采样率。忽略其中一个，截图就可能被误读。
