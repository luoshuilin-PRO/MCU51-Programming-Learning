# 07 故障排查与速查表

## 有问题时先按顺序检查

接线 → 安全地 → 通道开关 → 倍率 → 耦合 → Run/Stop → V/div → s/div → 触发 → 被测电路。不要第一反应恢复所有设置或换元件。

| 现象 | 常见原因 | 下一步 |
|---|---|---|
| 什么都没有 | 通道关闭、停止采集、位置在屏幕外 | 打开通道、Run、检查位置和量程 |
| 只有直线 | 直流、测到 GND、程序没运行、时间档不适合 | 先核对测点和直流电压，再改变时间档 |
| Normal 下不更新 | 没有符合触发条件的事件 | 检查源、方向和电平；临时 Auto 找信号 |
| 波形左右跑 | 触发源错、电平在信号范围外、信号不稳定 | Edge、正确源、中间电平，再看电路 |
| 幅值差十倍 | 探头开关和菜单不匹配 | 两者统一；默认设置后再次检查 |
| 波形顶部平了 | 超量程或电路削顶 | 增大 V/div；若仍削顶再查电路供电/范围 |
| 方波圆角明显 | 补偿不佳、带宽限制、RC 负载、边沿本来慢 | 校准端复测；记录带宽并比较测点 |
| 尖峰/振铃多 | 长地线、补偿、真实寄生振荡 | 短地线复测；不要先平均掉 |
| 5 V 电源变成零附近波动 | AC 耦合去掉直流 | 换 DC 看绝对电压 |
| 慢方波平台下垂 | AC 耦合高通效应 | 换 DC 后比较 |
| 频率随着时间档乱变 | 混叠、自动测量误判、复杂信号 | 增加有效采样率，用游标读实际周期 |
| Duty 或 Frequency 显示无效 | 不完整周期、非周期、截断或选错来源 | 显示完整波形，选正确通道 |
| 按 Single 后一直等待 | 触发事件未发生、极性/阈值不合适 | 查待触发状态，再产生目标事件 |
| 单次抓到的不是目标 | 先被噪声或其他边沿触发 | 提高条件选择性，重设阈值和时间范围 |
| CH2 接上后电路异常 | 地夹错接、探头负载或尖端短路 | 立即断电；先查地路径和接触位置 |
| 串口有波形但解码错 | 波特率、阈值、位数/校验/极性不匹配 | 先用游标测位宽 |
| MCU 测晶振后停机 | 探头负载干扰振荡 | 移除探头，改看分频输出并查推荐测法 |
| U 盘不识别 | 文件系统/设备兼容性 | 查官方兼容要求，不直接格式化资料盘 |
| Auto Setup 不好用 | 信号太慢、太小或不连续 | 手动设量程和触发，Auto 不是通用解法 |

## 开始设置速查

所有例子限已确认安全的低压电路，10X 探头与菜单匹配、DC 耦合起步。

| 任务 | V/div 起点 | s/div 起点 | 触发 |
|---|---|---|---|
| 校准方波 | 1 V/div，按幅值改 | 200 μs/div，按周期改 | CH1 上升沿、中间电平 |
| 5 V GPIO 约 1 kHz | 1 V/div | 200 μs/div | CH1 上升沿，约 2.5 V |
| 3.3 V GPIO 约 1 kHz | 500 mV/div～1 V/div | 200 μs/div | CH1 上升沿，约 1.65 V |
| 慢闪烁 | 1 V/div | 100～200 ms/div | 按目标边沿 |
| 按键 | 1 V/div | 1～5 ms/div | 按极性，Single |
| UART 9600 8N1 | 1 V/div | 100～200 μs/div | 空闲高时选下降沿 |
| RC τ = 100 μs | 输入输出各约 1 V/div | 20～50 μs/div 看边沿 | CH1 输入上升沿 |
| 电源启动 | 1 V/div | 10～100 ms/div | 电源上升沿，Single |
| 电源小纹波 | 10～50 mV/div，AC | 1 ms/div 和 10 μs/div 对比 | 按实际成分调整 |

“约 2.5 V”只适合确实 0～5 V 的信号。建议设置不会自动保证测量正确。

## 本周不需要掌握所有高级菜单

先完成探头补偿、手动调三项（电压档、时间档、触发）、读数、双通道 RC 实验。串口解码、FFT、远程控制放在这些之后。这样每次学习能有一个明确可验证的目标。
