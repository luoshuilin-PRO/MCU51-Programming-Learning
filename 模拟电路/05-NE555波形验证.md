# 综合课：用双通道示波器验证NE555

对应课件70–84页。先完成欧姆定律、LED限流、电容与RC。状态：待开始；理论设计未仿真、未实机测试。此课先验证振荡器，再考虑电子琴，不依赖Uno/ESP32。

## 器件与接线

需要已确认型号/封装的NE555、RA=1kΩ、RB=100kΩ、定时C=100nF、控制端10nF、供电去耦100nF、面包板。没有元件先计算。以实际厂商手册确认允许5V供电与引脚，不能根据芯片方向猜脚；其他555变体重新核对。

| 引脚（标准8脚555） | 接线 |
|---|---|
| 1 GND | 电源负端，统一参考地 |
| 8 VCC | 已核对的5V低压电源 |
| 4 RESET | 接VCC |
| 5 CONT | 10nF到GND |
| 7 DISCH | RA与RB中点；RA另一端到VCC |
| 2 TRIG、6 THRES | 两脚相连；RB另一端到此节点 |
| 定时C | 2/6节点到GND |
| 3 OUT | CH1探头测点，初次不接扬声器或MCU |
| 去耦100nF | 靠近芯片8脚与1脚 |

电源断开时搭线，检查供电极性和电容类型。先按电源教程验证限流，空载核对5V，再接电路；初次无外部负载可用约20mA的限制作为保守起点，若进入CC，先查短路、反接及器件供电需求，不能直接调大掩盖故障。

示波器两探头10X，通道倍率10X，DC耦合；两根地夹都只接电路GND。CH1接3脚，CH2接2/6节点；两通道地夹不能分别夹到两个信号点。确认供电与示波器保护地关系，不断开示波器保护地。

## 测量前先预测

标准无稳态接法：`tH≈0.693(RA+RB)C`，`tL≈0.693RB C`，`T=tH+tL`，`f=1/T`，高电平占空比`DH=tH/T`。

本组：tH≈7.00ms，tL≈6.93ms，T≈13.93ms，f≈71.8Hz，DH≈50.25%。5V时电容稳态振荡阈值约1.67V和3.33V；真实值有器件误差。OUT高电平不必精确到5V，需结合输出负载与数据手册。

电容充电阶段OUT高；升到约2/3VCC后OUT低、7脚放电开关导通；下降到约1/3VCC后OUT高、停止放电。上电首个充电周期与稳态周期可能不同。

## 双通道操作与输出

初始参考：CH1约1V/div、CH2约0.5–1V/div，时间约2ms/div，移好垂直位置，CH1上升沿触发，触发电平放在实际高低电平中间。这些是起点，根据实测调整；OUT非理想方波，CH2是指数充放电形状，不是直线三角波。

保存同屏照片或截图，游标量tH/tL和电容极值，计算f及DH；自动测量与游标互查。把预测/实测、RA/RB/C实值与容差写进表，偏差先从元件容差、接线、触发、供电及负载检查。

变式：断电后将C改为200nF（可用两只100nF并联），先预测周期约翻倍、频率约减半、高电平比例基本不变，再测。通过标准：能用两路波形解释输出翻转，能预测变式并解释偏差，不只会抄公式或让蜂鸣器响。

## 电子琴是下一步

课件82页按键改变定时电阻，从而改变频率。先做一个按键、算有效电阻并测频率，再扩展音符。被动蜂鸣器、扬声器与有源蜂鸣器不是同一负载；8Ω扬声器不能默认由OUT直接可靠驱动。核对负载、驱动电路、耦合电容极性与芯片电流能力后再接。NE555的5V输出也不得直接送进ESP32-S3的3.3V GPIO。
