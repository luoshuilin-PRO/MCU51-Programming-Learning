## 先怎么学

先读课件4–23页，完成起步课的闭卷计算，再做分压实验。之后学电容与RC、LED、晶体管，最后用NE555把电阻、电容和示波器串起来。没有实物元件时先纸上计算与仿真；仿真通过与实机通过分别记录。

你拥有TPR-3005-2D、DM40A、SDS1202X-E、Uno和两块ESP32-S3。前几课不需要编程；示波器用于观察随时间变化的电压，万用表用于直流读数、电阻与接线检查。不是所有概念都需要用示波器验证。
